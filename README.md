# Lumina Café

Marketing site for Lumina Café — hero, story, menu book, reservations and newsletter signup.

Built with Next.js 16 (App Router), Tailwind CSS 4, GSAP and Lenis.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Structure

```
app/          routes (/, /menu) and API routes (api/reserve, api/newsletter)
components/   page sections, menu book, nav, footer, ui primitives
lib/          menu data, form schemas, gsap setup, sprite/leaf layouts
public/       images and video
```
